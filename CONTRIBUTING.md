# Contributing

Thank you for your interest in contributing to this project.

## Toolkit repositories

Flow Toolkit repositories (the `tk-*` repositories, for example `tk-core`,
`tk-maya`, and `tk-multi-publish2`) share a single set of coding norms, maintained in
the tk-core repository:

[tk-core/CONTRIBUTING.md](https://github.com/shotgunsoftware/tk-core/blob/master/CONTRIBUTING.md)

Read it before opening a pull request. It applies to Toolkit repositories only.

## Other repositories

Repositories that are not part of Flow Toolkit, are not covered by the
Toolkit guidelines and can skip them. Follow the conventions of the repository you
are contributing to, and check whether it has its own `CONTRIBUTING.md`, which takes
precedence over this file.
